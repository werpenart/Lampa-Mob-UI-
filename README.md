# Lampa Mob UI

Мобильный интерфейс для [Lampa](https://github.com/yumata/lampa), собранный по макетам из Figma (файл «lampac»).
Включается только на телефонах. На ТВ и ПК Lampa выглядит как обычно.

## Подключение

**Настройки → Расширения → Добавить плагин**, адрес:

```
https://werpenart.github.io/Lampa-Mob-UI-/mob-ui.js
```

После добавления перезапустите Lampa.

## Что внутри

| Экран | Что меняется |
|---|---|
| Главная | шапка (меню, заголовок, уведомления, аватар), hero-карусель из первого ряда с автопрокруткой и паузой, ряды карточек 160×240 с бейджами «Фильм/Сериал», качеством, рейтингом, жанром и годом, широкие карточки «Продолжить просмотр» с прогрессом и серией |
| Нижняя панель | Главная, Поиск, Избранное, Настройки, кнопка «Назад» (кроме главной) |
| Боковое меню | профиль, пункты Lampa и плагинов с новыми иконками, активный раздел |
| Редактирование меню | чекбоксы видимости, перетаскивание за ручку, «Сбросить»/«Готово». Сохраняет в те же ключи, что и стандартный редактор (`menu_sort`, `menu_hide`) |
| Настройки | правая панель, новые иконки, плагины отделены разделителем |
| Поиск | поле с очисткой, история в виде чипов, источники-таблетки со счётчиком, результаты в рядах |
| Уведомления | нижний лист с постером, бейджами, датой и описанием |

В настройках появляется раздел **Mob UI**: в нём можно задать имя для шапки меню (буква аватара берётся из него).

## Разработка

Исходники лежат в `src/`:

- `src/main.js` — логика плагина;
- `src/style.css` — стили (px 1:1 с макетом 402×874);
- `src/icons/*.svg` — иконки, экспортированные из Figma.

Сборка в один файл `mob-ui.js`:

```
python3 build.py
```
